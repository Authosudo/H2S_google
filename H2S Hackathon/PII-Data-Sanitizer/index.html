PRIVACY ARCHITECTURE

Privacy Is Not an Option. It's Our Foundation.

Documents are processed locally inside your browser. No file or text ever leaves your device.

Client-Side Processing

All detection and redaction runs strictly in local browser JavaScript memory — even when offline.

No Cloud Uploads

There is no backend server. Enforced by Content Security Policy (connect-src 'none').

No External AI API

Your documents are never sent to external LLM endpoints or remote classification services.

No Unnecessary Tracking

Zero third-party scripts, analytics, cookies, or tracking pixels.

Secure Document Handling

Rendered strictly with safe DOM APIs (textContent) to prevent HTML/XSS injection, with binary file rejection.

Privacy-Focused Exports

CSV exports neutralize spreadsheet formula prefixes and audit reports never contain raw PII.
